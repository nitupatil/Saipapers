## Notes for website integration

- Use `chromo-barcode-label-roll-studio-hero.webp` as the main product gallery image.
- Use `object-fit: contain` and consistent image containers for responsive desktop/mobile layouts.
- Provide descriptive alt text based on the table above. Lazy-load supporting images.
- These are **AI-generated marketing illustrations**, not confirmed photographs of Sai Paper Product inventory. Some printed barcodes and numeric strings are illustrative and may not scan. Do not represent those examples as valid UPC/EAN codes.
- Final roll sizes, adhesive, materials, pricing, finish and print compatibility require confirmation before sale.
