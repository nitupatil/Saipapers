## Website integration

- Use `thermal-transfer-ribbons-studio-hero.webp` for the main product hero and `thermal-transfer-ribbon-rolls-color-range.webp` for the listing card.
- Use responsive image containers and `object-fit:contain` so rolls are fully visible on desktop and mobile.
- Descriptions above may be adapted as concise image `alt` text; use unique `alt` descriptions on each image.
- Images show concepts only, **not** verified photographs of products currently in stock. Any barcode or QR symbol is illustrative, not guaranteed to scan.
- The displayed roll colors do **not** establish ink type: wax, wax/resin or resin, winding, compatible media, ribbon length/width or printer requirements must be confirmed with the sales team.
